n = int(input())
s = [input() for i in range(n)]
ans = [['.' for i in range(2*n-1)] for i in range(2*n-1)]
ans[n-1][n-1] = 'o'
for i in range(n):
    for j in range(n):
        if s[i][j] == '.': continue
        ok = False
        for x in range(-n+1,n):
            for y in range(-n+1,n):
                if x==0 and y==0: continue
                ni, nj = i+x, j+y
                if 0<=ni<n and 0<=nj<n and s[ni][nj]=='.':
                    ok = True
                    if s[i][j]=='o':
                        for k in range(x,max(x,0),x):
                            if s[ni+k][nj+x-k]=='o': break
                            ans[ni+k][nj+x-k]='x'
                        for k in range(y,max(y,0),y):
                            if s[ni+y-k][nj+k]=='o': break
                            ans[ni+y-k][nj+k]='x'
                        for k in range(-x,min(-x,0),x):
                            if s[ni+k][nj+x+k]=='o': break
                            ans[ni+k][nj+x+k]='x'
                        for k in range(-y,min(-y,0),y):
                            if s[ni+y+k][nj+k]=='o': break
                            ans[ni+y+k][nj+k]='x'
        if not ok and s[i][j]=='x':
            print('NO')
            exit()
        if ok and s[i][j]=='o':
            for k in range(x,max(x,0),x):
                if s[ni+k][nj+x-k]=='o': break
                ans[ni+k][nj+x-k]='x'
            for k in range(y,max(y,0),y):
                if s[ni+y-k][nj+k]=='o': break
                ans[ni+y-k][nj+k]='x'
            for k in range(-x,min(-x,0),x):
                if s[ni+k][nj+x+k]=='o': break
                ans[ni+k][nj+x+k]='x'
            for k in range(-y,min(-y,0),y):
                if s[ni+y+k][nj+k]=='o': break
                ans[ni+y+k][nj+k]='x'
print('YES')
for i in range(2*n-1):
    print(''.join(ans[i]))
