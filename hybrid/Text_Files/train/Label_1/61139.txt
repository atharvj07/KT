from collections import defaultdict
n, m, t = map(int, input().split())
times = sorted([x for x in (input() for _ in range(n))])
time_steps = defaultdict(int)
used = set()
cnt = 0
ans = []
for time in times:
    # print(time, time_steps)
    step = 0
    while step + t > 86400:
        step += 86400
    while step < 86400:
        if time_steps[step] >= m:
            break
        used.add(time_steps[step])
        time_steps[step] += 1
        step += 1
    if max(used) + 1 > m:
        print("No solution")
        exit()
    else:
        cnt = max(cnt, max(used) + 1)
        ans.append(max(used) + 1)
print(cnt)
print(*ans)
