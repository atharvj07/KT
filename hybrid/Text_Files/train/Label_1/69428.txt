n, k = map(int, input().split())

# The maximum number of inversions is achieved when the array is in reverse order.
# For an array of length n, the maximum number of inversions is n * (n - 1) / 2.
# However, each swap can fix at most n - 1 inversions (by moving the smallest element to the first position or the largest to the last).
# We can perform k swaps, so we can reduce the maximum number of inversions by k * (n - 1).
# But there is a limit to this reduction. We cannot have negative inversions, and we cannot do more swaps than necessary to reverse the array.
# To reverse the array, we would need (n // 2) swaps (swapping first with last, second with second to last, etc.).
# So, the actual number of effective swaps is the minimum between k and n // 2.
# After utilizing the effective swaps, calculate the remaining maximum messiness.

# Calculate effective swaps.
effective_swaps = min(k, n // 2)

# Calculate maximum messiness after performing effective swaps.
# Remove the sorted pairs created by swapping.
max_messiness = n * (n - 1) // 2 - effective_swaps * (n - 1)

print(max_messiness)
