import sys
n,m=map(int,input().split());d,h=zip(*sorted([list(map(int,x.split())) for x in[input() for i in range(m)]]));j=0;z=0;f=True
for i in d:
	while j!=i:
		if z==h[j]:
			j+=1
		elif z==h[j]+1:
			f,z=True,z-1
			j+=1
		elif z==h[j]-1:
			f,z=True,z+1
			j+=1
		else:
			f=False
			break
	if not f:break
	if z>z:z=h[j]
if not f:print("IMPOSSIBLE")
else:print(z)
