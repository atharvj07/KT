from collections import Counter
n, m, p = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))
c = Counter(b)
ans = []
cou = 0
for i in range(n):
    d = Counter()
    for j in range(i, min(n, i + m * p, i + 100000)):
        d[a[j]] += 1
        if d == c:
            ans.append(i + 1)
            cou += 1
print(cou)
print(*ans)
