import math
import cmath
from decimal import *
from fractions import *
(n, q1, q2, k) = map(int, input().split())
a = list(map(int, input().split()))
b = [0] * n
for i in range(n):
	if 0 < a[i] % (q1 + q2) <= q1:
		continue
	a[i] %= q1 + q2
	if a[i] == 0:
		a[i] = q1 + q2
	a[i] -= q1
	b[i] = a[i] // q1 + (a[i] % q1 != 0)
b.sort()
dem = res = 0
for i in range(n):
	if dem + b[i] <= k:
		dem += b[i]
		res += 1
print(res)
