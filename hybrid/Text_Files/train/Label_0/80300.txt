from math import *
(n, a, b, k) = list(map(int, input().split()))
arr = list(map(int, input().split()))
count = 0
rem = []
for i in range(n):
	if arr[i] % (a + b) > 0 and arr[i] % (a + b) <= a:
		count += 1
	else:
		remPow = arr[i] % (a + b)
		if remPow == 0:
			remPow += b
		else:
			remPow -= a
		rem.append(remPow)
if rem != []:
	rem.sort()
	i = 0
	while k > 0 and i < len(rem):
		temp = ceil(rem[i] / a)
		k = k - temp
		rem[i] = 0
		if k > 0:
			count = count + 1
		if k == 0 and rem[i] <= 0:
			count += 1
		i += 1
print(count)
