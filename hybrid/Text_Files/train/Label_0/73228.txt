from operator import mul
(n, a) = map(int, input().split())
tab = list(map(int, input().split()))
a -= 1
(left, center, right) = (tab[:a], tab[a:a + 1], tab[a + 1:])
if len(left) >= len(right):
	print(sum(map(mul, right, list(reversed(left)))) * 2 + sum(list(reversed(left))[len(right):]) + sum(center))
else:
	print(sum(map(mul, reversed(left), right)) * 2 + sum(right[len(left):]) + sum(center))
