The JVM catches `StackOverflowError` on the same stack frame where it was thrown, not on the previous frame. When `f()` catches `StackOverflowError`, the call stack is already unwound to the current frame, allowing the method to continue executing. Since `f()` calls itself again after catching `StackOverflowError`, it reuses the same frame and repeats the overflow process indefinitely.

- Java SE 21 JVM Specification, Section 2.5.2 (Java Virtual Machine Stacks)
- Java SE 21 JVM Specification, Section 2.11 (Exceptions)
