**Why `src/` is needed:**  
- Prevents importing the package from the working directory during development.  
- Ensures tests/imports reflect installed package behavior, not local files.  
- Avoids namespace pollution when other modules are present in the root.  

**Disadvantages of no `src/` directory:**  
- Risk of importing from working directory instead of installed package.  
- `pip install .` may not work as expected due to import conflicts.  
- Testing could mistakenly use local files instead of installed package.  

**Recommendation:**  
Use `src/` structure for clean separation between source and build environment.
