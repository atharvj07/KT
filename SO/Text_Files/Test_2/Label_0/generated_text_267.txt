FastAPI automatically converts ORM model instances (SQLAlchemy models) to Pydantic schemas when returning responses. This works because of the 'orm_mode = True' setting in the Pydantic schema classes.

1. **crud.create_user_item returns a models.Item instance**:
   - The function in crud.py returns an instance of models.Item.
   - However, FastAPI, due to the response_model=schemas.Item in the route decorator, automatically converts the models.Item instance to a schemas.Item Pydantic model.

2. **How the conversion works**:
   - Pydantic models with 'orm_mode = True' can read from SQLAlchemy ORM instances.
   - When a models.Item instance is returned, FastAPI internally converts it into a schemas.Item response.

3. **The return type of crud.get_user**:
   - crud.get_user(db, user_id) returns models.User or None.
   - In the route handler @app.get("/users/{user_id}", response_model=schemas.User), FastAPI converts the models.User instance to schemas.User automatically.

Thus, FastAPI handles the transformation of SQLAlchemy models into response schemas transparently.
